読み込み中

各セクションを読んだら、すぐ下の数字をタップ。タップした時点で保存される。同じ数字をもう一度タップで取り消し。効く=進路・研究に直結/動ける=次の一手や試し方がある/初耳=知らなかった。

はじめの設定

記事と採点は非公開リポジトリ Waku68/asa-brief-data に入っている。読み書きするための「トークン」を1回だけ貼り付けてね。トークンはこのiPhoneの中にだけ保存される。

  1. GitHubのトークン作成ページを開く
  2. Token name：asa-brief、Expiration：好きな期限(最長1年)
  3. Repository access：Only select repositories → asa-brief-data だけ選ぶ
  4. Permissions → Repository permissions → Contents を Read and write
  5. 「Generate token」を押して出てきた github_pat_… をコピー

ホーム画面に置くには、Safariの共有ボタン →「ホーム画面に追加」。

まとめを読み込んでいます。
